# Metadata Standards

Each record should include:

- candidate_id → Unique ID for candidate
- job_id → Unique ID for job
- timestamp → When data was created
- model_version → Version of scoring system

## Example

{
  "candidate_id": "C001",
  "job_id": "J045",
  "score": 72,
  "timestamp": "2026-04-28",
  "model_version": "v1.0"
}
