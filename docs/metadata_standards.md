Transcript Metadata Standards – Zecpath AI

Core Metadata Fields

1. transcript_id
   Unique transcript identifier

2. candidate_id
   Unique candidate identifier

3. job_id
   Job reference identifier

4. question_id
   Question reference

5. confidence_score
   Speech-to-text confidence level

6. start_time
   Answer start timestamp

7. end_time
   Answer end timestamp

8. duration_seconds
   Answer duration

9. language
   Language spoken

10. created_at
    Transcript creation timestamp

Design Principles

• Consistency
• Traceability
• Auditability
• Scalability

Supports:

• Multi-language interviews
• Multi-round screening
• Future AI evaluation modules
