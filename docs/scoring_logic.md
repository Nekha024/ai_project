# HR Interview Scoring Logic

## HR Score

```
HR Score

=

(Relevance × Weight)

+

(Communication × Weight)

+

(Confidence × Weight)

+

(Consistency × Weight)
```

Default Weights

| Component | Weight |
|-----------|--------|
| Relevance | 30% |
| Communication | 25% |
| Confidence | 25% |
| Consistency | 20% |

---

## Unified Score

```
Final Score

=

ATS × 0.30

+

Screening × 0.30

+

HR × 0.40
```

Decision Rules

| Score | Decision |
|--------|----------|
| ≥75 | Hire |
| 55–74 | Consider |
| <55 | Reject |
