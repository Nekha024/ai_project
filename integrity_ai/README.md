AI Integrity & Malpractice Detection Framework

Objective
---------
Detect possible cheating or external assistance during AI interviews.

Signals Monitored
-----------------
1. Browser Tab Switching
2. Screen Focus Loss
3. External Voice Detection
4. Eye Gaze Deviation
5. Behavioral Signals

Pipeline
--------
Browser Activity
        ↓
Focus Detection
        ↓
Audio Analysis
        ↓
Behavior Analysis
        ↓
Pattern Recognition
        ↓
Risk Scoring
        ↓
Warnings
        ↓
Recruiter Dashboard

Risk Levels
-----------
75–100  : Low Risk
50–74   : Moderate Risk
0–49    : High Risk

Advantages
----------
• Non-invasive
• Easy integration
• Real-time alerts
• Recruiter friendly

Limitations
-----------
• Browser permission dependent
• Threshold-based
• False positives possible

Future Improvements
-------------------
• ML anomaly detection
• Voice identity verification
• Adaptive thresholds
