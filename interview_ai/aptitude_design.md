# Aptitude AI Module – Zecpath

## Objective

Evaluate a candidate's logical reasoning, structured thinking,
problem-solving ability and situational judgement.

## Core Components

1. Question Engine
   - Logical reasoning
   - Situational judgement
   - Analytical thinking

2. Answer Understanding
   - Reasoning extraction
   - Structured thinking
   - Decision patterns

3. Scoring Engine
   - Logical structure
   - Problem-solving
   - Decision quality

4. Scenario Evaluator
   - Compare with ideal answer patterns
   - Evaluate effectiveness

5. Output
   - Aptitude score
   - Breakdown
   - Scenario score
