Machine Test AI Framework – Zecpath

Objective
---------
Evaluate practical technical skills using coding tasks, debugging exercises,
file-based assignments, and mini system design challenges.

Architecture
------------
Candidate IDE / Web Editor
        ↓
Code Capture Engine
        ↓
Execution Engine
        ↓
Test Case Evaluator
        ↓
Code Quality Analyzer
        ↓
Time Analyzer
        ↓
Machine Test Scoring Engine
        ↓
Report Generator

Evaluation Metrics
------------------
• Correctness
• Runtime Efficiency
• Code Quality
• Problem Solving
• Time Taken

Scoring Formula
---------------
Task Score =
(Correctness × 40%) +
(Efficiency × 20%) +
(Code Quality × 20%) +
(Problem Solving × 20%)

Final Score =
(Task Score × 80%) +
(Time Score × 20%)

Performance Levels
------------------
80–100  Excellent
65–79   Good
50–64   Average
Below 50 Needs Improvement
